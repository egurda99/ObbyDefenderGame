## 📖 О проекте

**ObbyDefenderGame** - это увлекательная Tower Defense игра, разработанная на Unity, где игроку предстоит защищать свою базу от непрерывных волн врагов, стратегически размещая различные типы башен и улучшая их характеристики.

### 🎯 Основная цель
Не дать врагам пройти по пути и добраться до вашей базы, используя оружие героя и установку защитных турелей.

## ✨ Особенности

### 🎮 Геймплей
- **Турели** - защищают базу от врагов
- **Система улучшений** - прокачивайте башни и героя для увеличения урона, скорости атаки и здоровья
- **Разнообразные враги** - от быстрых легких юнитов до медленных танков с большим запасом здоровья и дальними атаками
- **Система волн** - с каждой волной враги становятся сильнее и многочисленнее.
- **Экономическая система** - зарабатывайте монеты за уничтожение врагов и тратьте их на новые апгрейды

### 🛠️ Технические особенности
- Оптимизированная производительность для плавного геймплея
- Адаптивный AI врагов с системой поиска пути
- Визуальные и звуковые эффекты для полного погружения
- Система сохранения прогресса
- Поддержка различных разрешений экрана

## 🚀 Технический стек

### Основные технологии
- **Unity Engine** (2021.3 LTS или выше)
- **C#** - основной язык программирования
- **Visual Studio 2022** / **Visual Studio Code** - IDE

### Архитектура проекта
```
ObbyDefenderGame/
├── Assets/
│   ├── Scripts/
│   │   ├── Towers/          # Логика башен
│   │   ├── Enemies/         # Поведение врагов
│   │   ├── Managers/        # Игровые менеджеры
│   │   ├── UI/              # Интерфейс пользователя
│   │   └── Utils/           # Вспомогательные скрипты
│   ├── Prefabs/             # Префабы объектов
│   ├── Materials/           # Материалы и шейдеры
│   ├── Textures/            # Текстуры и спрайты
│   ├── Audio/               # Звуковые эффекты и музыка
│   └── Scenes/              # Игровые сцены
├── Packages/                # Unity пакеты
├── ProjectSettings/         # Настройки проекта
└── README.md
```

### Используемые паттерны
- **Singleton** - для игровых менеджеров
- **Object Pooling** - для оптимизации спавна врагов и снарядов
- **Observer Pattern** - для системы событий
- **Strategy Pattern** - для различных типов атак башен

## 📦 Установка

### Требования
- Unity 2021.3 LTS или выше
- Git
- Минимум 4 GB RAM
- 2 GB свободного места на диске

### Клонирование репозитория
```bash
git clone https://github.com/egurda99/ObbyDefenderGame.git
cd ObbyDefenderGame
```

### Открытие в Unity
1. Откройте Unity Hub
2. Нажмите "Add" и выберите папку проекта
3. Откройте проект в Unity Editor
4. Дождитесь импорта всех ассетов

## 🎮 Быстрый старт

### Управление
- **Левая кнопка мыши** - выбор и размещение башен
- **Правая кнопка мыши** - отмена действия
- **ESC** - пауза / меню
- **Пробел** - ускорение игры
- **1-5** - быстрый выбор типа башни

### Типы башен
| Башня | Описание | Урон | Скорость | Стоимость |
|-------|----------|------|----------|-----------|
| 🏹 **Лучник** | Базовая башня с средним уроном | Средний | Быстрая | 100 💰 |
| 🔥 **Огненная** | Наносит урон по области | Высокий | Медленная | 200 💰 |
| ❄️ **Ледяная** | Замедляет врагов | Низкий | Средняя | 150 💰 |
| ⚡ **Электро** | Цепная атака по нескольким целям | Средний | Средняя | 300 💰 |
| 💣 **Пушка** | Огромный урон одной цели | Очень высокий | Очень медленная | 500 💰 |

## Почему выбран такой стиль и тема проекта

- На момент выполнения проекта, ниша итальянских животных имела резкий рост и была в тренде + Обби устаявшийся тренд.
- Так как игра ориентировалась на детскую аудиторию и веб площадку: подобранные визуальный стиль и ниша были оправданы.
- Скриншоты популярности трендов

### Стиль кода
- Используйте camelCase для переменных и методов
- Используйте PascalCase для классов и публичных свойств
- Добавляйте XML комментарии к публичным методам
- Следуйте принципам SOLID

## 🐛 Известные проблемы

- Иногда враги могут застревать на поворотах пути
- Звуковые эффекты могут накладываться при большом количестве башен
- UI может масштабироваться некорректно на ультраширокоформатных мониторах
